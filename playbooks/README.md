# Playbooks Documentation

This document provides guidance on using Azure Logic Apps playbooks for automated incident response in Microsoft Sentinel.

## What are Playbooks?

Playbooks are automated workflows built using Azure Logic Apps that respond to security incidents generated by Microsoft Sentinel. They help reduce response time and ensure consistent handling of alerts.

## Example Use Cases

1. **Auto-Close Low Severity Incidents**
   - Automatically close incidents where the severity is "Low"
   - Reason: Resolved - False Positive

2. **Email Notification for High Severity Alerts**
   - Sends an email to the security team when a high-severity incident is created
   - Can include details like alert name, timestamp, and entities involved

3. **Post Notification to Microsoft Teams**
   - Posts an adaptive card in a Teams channel with incident details
   - Useful for real-time collaboration in SOC environments

## Playbook Integration Steps

1. Go to Microsoft Sentinel > Automation > Playbooks
2. Click **+ Add Playbook** > Create a blank Logic App
3. In Logic App Designer:
   - Set the trigger: "When a response to an Azure Sentinel alert is triggered"
   - Add necessary actions (Send Email, Close Incident, Post to Teams)
4. Save and Test the playbook
5. Go back to Sentinel > Automation and attach the playbook to the appropriate automation rule
